# 📝 Python To-Do List

A simple Command Line Interface (CLI) To-Do List application developed in Python.

## 🚀 Features

- ➕ Add multiple tasks
- ✏️ Update existing tasks
- 📋 View all tasks
- ❌ Remove a task
- 🗑️ Clear all tasks
- 🔄 Menu-driven interface

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
ToDoList.py
README.md
```

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/python-todo-list.git
```

2. Open the project folder

```bash
cd python-todo-list
```

3. Run the program

```bash
python ToDoList.py
```
